# v1.1.0：备份与维护可靠性更新

建议使用此版本进行新的 Windows 部署。沿用单文件、Python 标准库实现，脚本约 7 KiB，无需第三方依赖。

## 相比初始版修复了什么

- Windows 跨进程锁阻止维护任务重叠；锁文件固定为 1 字节。
- 验证有效备份后清理遗留临时备份，备份退出时清理本次临时文件。
- 备份分页检查 30 秒截止时间，超时保留原备份并跳过本轮删除。
- WAL 回收繁忙时返回 `checkpoint_busy`，不再误报 `ok`。
- 准确统计删除条数，修复可能显示 `-1` 的问题。

## 公开分发与升级

- 项目和仓库更名为 ChatGPT Log Guardian / `chatgpt-log-guardian`，公开脚本名为 `chatgpt_log_guardian.py`。旧任务需要核对脚本参数；底层 `.codex` 路径、备份与锁名称保持兼容。

- 移除个人绝对路径；日志默认位于当前用户 `.codex`，可通过 `CODEX_HOME` 指定目录。
- 主备份与锁文件默认放在脚本旁，该目录必须可写。
- 正确编码 SQLite 文件 URI，支持包含空格、`#` 等字符的日志目录。
- 保持 50 MiB 日志估算预算、120 MiB 数据库与 WAL 合计维护阈值。
- 补齐中文 README、更新日志、独立数据库回归测试和敏感运行文件忽略规则。
- README 开头提供 ChatGPT/Codex 部署提示词及用法，另附更新后兼容性复查和暂停维护提示词。

下载附件 `chatgpt_log_guardian.py`，使用 Windows Python 3.10+ 运行。`SHA256SUMS.txt` 提供附件校验值。升级后检查已有计划任务的脚本和 Python 路径；新路径规则可能使备份位置与旧版不同。

## 验证与边界

9 项回归测试覆盖正常清理及备份、其他表保持不变、锁互斥和固定大小、备份超时不清理源记录、不覆盖原备份、WAL 繁忙报告、准确删除条数、默认路径及特殊字符目录。已在 Windows、Python 3.12.14 环境通过；未将其他 Python 版本或所有 ChatGPT/Codex 版本标记为实测通过。测试使用独立数据库，不清理真实用户日志。

30 秒是分页回调和校验边界上的截止检查，不是整个脚本的强制总时限。维护阈值不是磁盘硬上限。超限备份、压缩及数据库锁竞争可能短暂占用资源；不保证所有未来 ChatGPT/Codex 版本兼容。

脚本不操作系统关键文件、正式聊天历史或长期记忆存储，不发送网络请求，也不自动创建计划任务。诊断日志可能含内容副本，删除会减少排障线索；备份应按敏感文件保管。

完整使用说明见 [README](https://github.com/Needy1100/chatgpt-log-guardian#readme)，历史变更见 [CHANGELOG](https://github.com/Needy1100/chatgpt-log-guardian/blob/main/CHANGELOG.md)。
