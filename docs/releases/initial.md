# 初始公开版：诊断日志备份与清理

这是 2026-09-20 发布的历史版本，原标签为 `脚本文件`，对应提交 `ce01813a8eed2ad8ef66b1109543ad32d874b68a`。保留原标签和原附件，便于核对；新部署请使用 [v1.1.0](https://github.com/Needy1100/chatgpt-log-guardian/releases/tag/v1.1.0)。

## 本版功能

- 对 Codex `logs_2.sqlite` 生成 SQLite 一致性备份，并进行完整性检查。
- 日志估算量超过 50 MiB 时删除较旧记录，保留最新日志。
- 数据库与 WAL 合计超过 120 MiB 时尝试压缩。
- 执行 WAL checkpoint，输出不含日志正文的 JSON 摘要。

## 已知限制

- 使用作者本机的绝对路径，其他电脑不能直接照搬。
- 没有跨进程维护锁、备份总截止检查和遗留临时备份清理。
- checkpoint 繁忙时可能仍报告成功；删除条数可能显示 `-1`。

这些限制已在 v1.1.0 中修复。本页说明根据该标签下的代码补写，不代表这些修复已包含在旧附件中。

诊断日志及备份可能含请求或工具相关内容，请按敏感文件保管。维护阈值不是磁盘硬上限。
